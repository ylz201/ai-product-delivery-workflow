# User Preferences

## Workflow Preferences

- Prefer controlled, measurable evolution over uncontrolled feature expansion.
- Prefer runnable patches over abstract design notes.
- Prefer Git-trackable Markdown/JSON files over hidden memory systems.
- Prefer simple static HTML visualization before complex dashboards.
- Prefer agent workflows that preserve user control and expose risks.

## Agent Behavior Preferences

- Do not repeatedly ask broad questions when reasonable assumptions can be made.
- Do not stop at planning when the request is to create or modify files.
- Report exactly what changed and how it was verified.
- Keep old project takeover safe: no refactor before baseline.
- Use Master Agent and Architect Agent when project complexity requires coordination.

## Documentation Preferences

- Maintain project memory.
- Maintain decision records.
- Maintain mistakes and process fixes.
- Keep TODO actionable and measurable.
- Keep dashboard local, simple, and easy to inspect.
