# Reusable Patterns

## Pattern: File-Based Memory Before Infrastructure

Use Markdown files for stable project memory and JSON files for run records before introducing a database or vector store.

## Pattern: Static Dashboard Before Observability Platform

Use `docs/dashboard/index.html` plus generated JSON files for local visualization before adding a backend dashboard.

## Pattern: Legacy Assimilation Before Refactor

For old projects, first create safety check, inventory, As-Is architecture, recovered product contract, capability matrix, baseline report, and migration roadmap.

## Pattern: Master Agent Controls Scope

The Master Agent should select mode, allocate specialist agents, maintain contracts, enforce verification, and prevent false completion.

## Pattern: Evidence-Based Handoff

Every delivery handoff should include changed files, commands run, verification result, blockers, risks, and next actions.
